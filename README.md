# Kvíz z organizace a podnikatelských projektů

Interaktivní kvíz s 89 otázkami z testu na primat.cz. U každé otázky je správná odpověď a vysvětlení.

**Otevřít kvíz:** https://vladsc23.github.io/kviz-organizace-projekty/

## Co umí

- volba počtu otázek (10, 20, 30, 50, všech 89 nebo vlastní počet), zamíchané pořadí
- po každé odpovědi hned správná odpověď a vysvětlení
- historie pokusů s procenty a grafem, procházení každého pokusu
- přehled všech otázek se statistikou, kolikrát jsi kterou měl správně a špatně
- režim „Jen chybné otázky“
- výzvy mezi kamarády: všichni dostanou stejné otázky, výsledky si pošlete zprávou a kvíz sestaví pořadí

Historie se ukládá v prohlížeči každého hráče. Nepotřebuješ žádný účet.
